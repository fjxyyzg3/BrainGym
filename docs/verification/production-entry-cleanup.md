## Residual Risk

已完成本地及远端可达 Git 历史的脱敏，不能据此宣称 GitHub 后端旧对象已清除。GitHub 的缓存、悬空对象及服务器垃圾回收需要通过平台支持评估处理；[GitHub 官方说明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)明确指出强推后旧 SHA 仍可能可访问，且支持团队只处理符合其敏感数据标准的请求，不保证受理入口标识类清理。当前尚未向支持团队提交申请。

其他克隆、构建镜像或外部日志不在本次可验证范围；持有旧克隆的人应重新克隆，或单独清理，不能将旧历史合并回已脱敏分支。原始备份和截图私有副本按用户要求保留，既有未跟踪技能文件未改动。本次未发现真实凭据泄露证据，未轮换正式凭据；本页不记录真实入口值或原受影响 SHA。
