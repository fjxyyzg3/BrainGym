## 可观察结果与证据

- **路径与安装资源**：`tests/pwa.test.ts` 验证两个基础路径下的 manifest 媒体类型、标识、启动地址、scope、图标地址、worker 更新头、安全头和 API `no-store`；缺失 worker 返回 404，不能成为 SPA HTML。`tests/e2e/pwa.spec.ts` 用隔离普通配置目录调用 Chrome CDP，可安装性错误为空，四种 PNG 尺寸正确。没有新增安装按钮、横幅或主动安装调用。
- **离线与身份**：真实 worker 完成缓存后关闭页面、断网重开，训练大厅与准备页可用，主动选择游客后完成对局得 50.0 分。恢复网络没有成绩 POST；登录后断网选择游客不清 Cookie，联网后原会话仍可验证，历史没有新增结果。
- **私人数据**：浏览器确认私人历史接口响应来自网络而非 worker，401 和 `no-store` 保持；枚举缓存没有 API URL、测试 Token 或测试用户名。localStorage 无新增数据，IndexedDB 无离线队列。
- **更新等待**：两套真实 Vite 发行版本由实际 Fastify 实例交付。在两页面打开、对局进行及保存失败待重试时，新 worker 只进入 waiting，页面不刷新、待重试结果保留；关闭所有旧页面后打开新版，发行标记改变，启动训练大厅。
- **失败与回收**：分别注入脚本摘要损坏、资源 HTTP 503 和 HTML 发行标记错误，旧版均仍能离线打开；恢复正常资源后可再次准备更新。哨兵缓存代表另一个基础路径，更新清理后仍保留。worker 脚本 503 时在线练习仍能开局；通过 CDP 将存储配额设为 1 字节，安装失败不阻断在线使用、不会留下可见的半成品缓存，解除配额后重新打开可安装成功。
- **缓存读取故障**：`tests/pwa-worker.test.ts` 在 VM 中运行实际 worker，只替换失败的 Cache Storage 边界，验证真实 Fetch API 请求仍得到真实回环 HTTP 响应；此项不是浏览器存储设备故障的真机复现。
- **既有业务**：原浏览器回归保留游客不补传、移动端输入去重、结果手动重试/刷新丢弃、丢失响应幂等、跨账户拒绝、会话失效及原生 Chromium CDP 后台作废。服务端测试保留撤销/换发、会话有效期、数据隔离、服务端计分、来源校验与客户端 IP 限流。
- **开发与视觉**：注册入口由 `import.meta.env.PROD` 限定，开发模式不注册新 worker，此项为源码检查。390×844 模拟视口的离线准备页和游戏页已截图检查：无横向溢出，游客动作可见，游戏操作按钮可见；模拟视口没有真实安全区或软键盘，不能代替真机。

## RED/GREEN 与测试环境修正

1. 原实现的 manifest 请求没有正确类型，缺失 worker 被回退为 HTML，新增 3 项 HTTP 断言失败；实现后同命令全部通过。
2. 真实缓存已可离线打开、但尚未增加显式游客动作时，离线冷启动测试因找不到“以游客身份练习”失败；增加动作后通过。
3. 缓存读取失败最初导致 worker 请求失败；针对真实 HTTP 返回的测试出现 `cache read unavailable`，增加网络回退后通过。
4. 浏览器 worker 脚本请求不在 page 的 response 流中。注册失败用例改为观察实际隔离 HTTP 服务收到的请求，并继续断言在线游戏可用，没有削弱功能断言。
5. Chrome 在隐身上下文报告 `in-incognito`。可安装性用例改为临时普通配置目录，不忽略错误，实际安装条件错误数组为空；验证后关闭浏览器并删除自己的临时目录。
