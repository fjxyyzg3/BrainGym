## 失败基线与修正

- 服务端 RED：未实现时，新模式 POST 返回 400 而期望 200；未知模式查询返回 200 而期望 400。实现后相同测试通过。
- 浏览器 RED：未实现时找不到“位置＋颜色 N-back”卡片；接入后通过。既有单卡片选择器改为按空间卡片定位，原断言保留。
- 分项分数断言最初漏了界面中的“分”单位，修正为完整显示文字；迟到响应测试改为按实际挂起响应逐一释放，并用空间 1 局、双路 0 局的不同数据验证隔离，不依赖固定请求次数。
- 最佳原始精度用例最初两组均值跨越显示舍入边界；改用两组均显示 25.9、原始值不同的合法统计，验证确实按未舍入值比较。
- 全套 PWA 更新用例发现子页标题更新覆盖了构建提供的首页标题；修复为首页保留构建标题，子页附加页面名称。保留原有新版本标题断言，之后完整门槛全部通过。
