## 原生后台与渲染

使用 `scripts/check-native-visibility.mjs`，设置 `VISIBILITY_GAME=task-switching`，在独立回环 3198 服务和显式隔离数据库下，分别执行 `VISIBILITY_TASK_SWITCHING_PHASE=question`、`feedback`、`complete`。原生 Chromium CDP 创建并激活另一标签页，真实隐藏事件使前两种状态作废且写请求为 0；末题判定后保留完整结果，写请求恰为 1。未伪造 `document.hidden` 或隐藏事件，验证服务结束后停止。

整合后再次以显式 Chromium 路径及 `NATIVE_VISIBILITY_DATABASE` 运行三相位，结果仍为中断上传 0／完整上传 1；同时复验心理旋转末题完成和 Stroop 反馈分支，均通过，隔离服务已停止。首次复验因未设置 Chromium 路径在浏览器启动前退出，补齐环境后重跑，未修改产品或断言。
