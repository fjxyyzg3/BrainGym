> 摘要：二维心理旋转的轮廓生成、混合配额、回执计时、分类指标、私人记录及独立成绩合同。

# 心理旋转

大厅中的“心理旋转”进入 `#mental-rotation` 准备页。每题同时显示参考图和待判断图，玩家选择“仅旋转”或“镜像”。“镜像”指参考图需要先左右翻转，再转动才能得到待判断图。图形保持静态，不提供手动旋转或专用快捷键；两个原生按钮按“仅旋转、镜像”固定排列，支持鼠标、触屏和原生键盘操作。

## 题目与图形

正式局固定 32 题，将下列分类的每一种组合各出 2 题，再随机排序：

| 分类       | 候选                  |
| ---------- | --------------------- |
| 图形复杂度 | 简单 6 格、复杂 10 格 |
| 旋转角度   | 45°、90°、135°、180°  |
| 正确关系   | 仅旋转、镜像          |

图形是沿边连通、无孔洞的方块组合，以同色实心外轮廓显示，不显示内部格线。生成器排除非零旋转对称、镜像可旋转重合及边界相交的形状；同局按平移、旋转和镜像等价去重，不要求跨局去重。每个形状最多随机尝试 128 次，不足时从对应复杂度的 16 个已验证备用轮廓中补齐。即使合法随机源始终返回同一值，也能在有限次尝试后完成出题；非法随机值或内部生成失败时显示错误，不开始部分对局。

基础朝向从四种直角朝向中选择，非 180° 的旋转方向等概率选择。镜像题先左右翻转参考图，再绕中心按指定角度旋转；分类角度表示出题变换，不表示玩家实际采用的脑内旋转路径。两图使用同一比例尺和共同的正方形 viewBox，保留旋转所需的留白，不独立拉伸、填满或裁切。

可选的 8 题热身覆盖两种复杂度、四个角度和两种答案，不要求覆盖全部交叉组合。热身不保存、不更新最佳，结束后显示本地统计；正式局需手动开始，重新出题、清零统计并核对身份。

## 计时与中断

每题不限时，不设置超时或跳题。题面的提交回执到达后，以 `performance.now()` 建立起点，只接受首次有效回答。回答后保留两图，显示正误及正确答案；反馈的独立提交回执到达后，等待满 800 ms 才进入下一题。

每个题面和反馈都有交付标识。重复或过期回执不重置时钟，迟到调度不消耗尚未展示的题目。指针与原生键盘激活绑定开始时的题目，跨题释放、长按重复及反馈期输入不能替下一题作答。正确题耗时按单题经过时间舍入为整数毫秒再累加；DOM 回执不能证明屏幕像素的实际呈现时刻。

主动结束、离开、切换游戏、切后台或锁屏使未完成局作废，不能暂停或续局，题间反馈同样受此约束。末题判定时立即冻结完整摘要和完成时间，随后展示末题反馈；之后切后台不撤销结果。旧开局身份响应或保存回调不能重启已经离开的训练页。

## 指标与私人记录

结果、整局最佳和历史分别展示整体、四个角度及两种复杂度的正确／错误数、准确率和正确题平均用时，不展开交叉表或逐题回看。

- 准确率为 `100 × 正确题数 / 本组总题数`；正式局整体分母为 32。
- 正确题平均用时只累计正确回答的耗时，不包含准备、错误题、反馈或网络请求；没有正确题时为 `null`，界面显示“—”。
- 准确率显示一位小数，用时显示整数毫秒；展示舍入不参与最佳比较。分类分母不相加，各分类都是同一局的不同视角。

最佳按同一用户、游戏和规则版本选择：准确率高者优先，相同时正确题平均用时短者优先；仍相同时按首次入库时间、结果 ID 升序选择。完整零正确局仍保留历史；全部零正确时按稳定次序选择最佳，用时仍显示“—”。各分类来自同一个最佳局，不拼接不同局的分类最佳。

历史每页 20 条，按完成时间、首次入库时间和结果 ID 倒序排列。结果页进入记录时选中心理旋转，记录内训练入口返回其准备页；普通记录入口仍默认空间 N-back。切换账号、模式或页码使旧请求失效。

## 数据与信任边界

游戏标识为 `mental-rotation`，规则版本为 `1`，使用独立 `MentalRotationGame`。`RotationSummary.groups` 保存“复杂度 × 角度 × 正确关系”的 16 个分类，每类包含 `correct`、`wrong`、`correctRtTotalMs`。正式摘要每类的正确题数与错误题数之和必须为 2；次数和耗时均为非负安全整数，全部正确耗时的和也必须为安全整数；零正确组的总耗时必须为 0。不为不限时训练设置额外的固定耗时上限。

`POST /api/results` 接收 ID、开局用户 ID、游戏、版本、严格 UTC 完成时间和分类汇总。服务端验证固定分类、配额和数值范围，按固定顺序规范化并复算准确率及平均用时。缺失／重复／未知分类、非法值和错误配额返回 400，沿用 Origin、有效会话和 8192 字节请求体限制。浏览器负责真实出题和判断，服务端不核验实际游玩过程；题面、逐题选择和逐题用时不上传或持久化。

`mental_rotation_results` 是 schema 1 的附加表，初始化过程具有原子性且可重复执行，核心 `PRAGMA user_version` 不变。保存事务在 N-back、Corsi、Stroop 和心理旋转四张成绩表中检查同用户结果 ID：规范化内容相同返回首次记录，变更内容或游戏返回 409；字段或分类顺序变化不引发假冲突。发布指纹保护新表存在性与既有行，旧程序可忽略附加表，程序恢复不删除它、不回滚数据库。

账号正式局开局时重新确认身份，成绩归属最终由有效服务端会话决定；`startedByUserId` 只作前置校验，换账号后原局不能转存。保存失败可在当前页按原请求手动重试，刷新或离开后不恢复。游客和热身不发保存请求，登录或联网后也不补传。PWA 只缓存公共构建资源，私人 API、凭据和待保存数据不缓存；游客及热身可在缓存完成后离线进行。
