# 空间 N-back 规则

首版游戏标识为 `spatial-n-back`，规则版本为 `1`。玩家选择 N＝1～5，每局保持不变。

一局先展示 N 次作为记忆起点，再进行 30 次有效判断。每步 2.5 秒：亮起 0.5 秒，留空 2 秒。起始展示不接受输入；有效判断在亮起和留空时段都可作答。点击、触屏或按空格表示匹配，不操作表示不匹配，每步只接受首次输入。长按空格的重复事件不重复计数。

起始格子从九个位置等概率选择。每次有效判断以 30% 概率与 N 步之前的位置相同，否则从另外八个位置等概率选择。整局匹配总数不固定；如果生成序列缺少任一题型，就重抽整局，保证两类分母都大于零。

| 事实 | 输入匹配 | 不操作 |
| --- | --- | --- |
| 与 N 步前相同 | 命中 TP | 漏报 FN |
| 与 N 步前不同 | 误报 FP | 正确拒绝 TN |

平衡准确率为 `100 × (TP / (TP + FN) + TN / (TN + FP)) / 2`。四类次数合计 30。全对为 100 分，每次判断都错误为 0 分，完全不操作为 50 分。界面显示一位小数，最佳成绩使用未舍入值，1～5-back 分别比较。

主动结束、离开游戏页、切后台或锁屏会使未完成对局作废，不能暂停或续局。已完成结果在当前页面保留；上传失败可以手动重试，刷新或离开后不恢复待上传数据。完成后切后台不会撤销结果。
