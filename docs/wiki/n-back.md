# N-back 规则

大厅提供“空间 N-back”（`spatial-n-back`）与“位置＋颜色 N-back”（`spatial-color-n-back`），各自的规则版本为 `1`。玩家选择 N＝1～5，一局内保持不变；双路模式的位置与颜色共用同一个 N。原空间模式的规则和已有成绩含义保持不变。

## 时序与中断

一局先展示 N 次作为记忆起点，再进行 30 轮有效判断。每步 2.5 秒：亮起 0.5 秒，留空 2 秒；起始展示不接受输入、不计分。有效判断在亮起和留空期间都可作答，长按键盘产生的重复事件不计入当前或后续轮次。时序由单调时间推进。

主动结束、离开游戏页、切换训练模式、切后台或锁屏会使未完成对局作废，不能暂停或续局。已完成结果在当前页面保留，之后切后台不撤销结果。上传失败可以手动重试，刷新或离开后不恢复待上传数据；游客结果不在登录后补传。

## 空间模式

九宫格每次亮起一个位置。当前位置与 N 步前相同时，点击“匹配”、触屏或按空格；不相同则不操作。每轮只接受首次输入，标记不可撤销。

起始格子从九个位置等概率选择。每次有效判断以 30% 概率与 N 步之前的位置相同，否则从另外八个位置等概率选择。整局匹配总数不固定；如果生成序列缺少任一题型，就重抽整局，保证两类分母都大于零。

## 位置＋颜色模式

每步在九宫格的一格呈现一种颜色，使用固定的蓝、橙、紫、绿、玫红、金 6 色。亮起结束后位置和颜色都留空，作答窗口仍持续到下一步。

| 维度 | 匹配条件                    | 操作               |
| ---- | --------------------------- | ------------------ |
| 位置 | 当前格与 N 步前的格相同     | “位置匹配”按钮或 F |
| 颜色 | 当前颜色与 N 步前的颜色相同 | “颜色匹配”按钮或 J |

两个维度独立判断。两者都匹配时两个按钮都要按，不匹配的维度不操作。每轮每路只接受首次输入，标记一路不影响另一路；支持同轮同时或先后输入。按钮只反馈已标记，不即时提示正误。

两路序列独立生成：初始位置和颜色分别从九格、六色中等概率选择；每路在有效轮均以 30% 概率匹配各自 N 步前的值，否则从该路其余候选值中等概率选取。某一路全匹配或全不匹配时只重抽该路。每路均有两种题型，但每局不固定匹配数量、同时匹配次数或四种组合的数量。

## 统计与分数

每个启用的维度分别统计：

| 事实          | 输入匹配 | 不操作      |
| ------------- | -------- | ----------- |
| 与 N 步前相同 | 命中 TP  | 漏报 FN     |
| 与 N 步前不同 | 误报 FP  | 正确拒绝 TN |

每路四类次数合计 30；匹配与不匹配两类分母均大于零。平衡准确率为 `100 × (TP / (TP + FN) + TN / (TN + FP)) / 2`。空间模式以此为成绩；双路模式先分别计算位置、颜色分数，再将两路未舍入分数取算术平均作为综合分。两路全对为 100 分、全错为 0 分，完全不操作为 50 分。

界面显示一位小数，最佳使用未舍入分数，按模式、规则版本及 1～5-back 分别比较。双路结果和历史展示两路分项，不把两组统计合并为一次 60 题的单路计分。服务端按相同规则复算成绩，不信任客户端提供的分数。

## 个人记录与导航

结果页的“查看个人记录”选中本局模式。记录页可切换模式，切换后回到第一页；“开始训练”和空列表中的“开始第一局”进入当前所选模式的准备页。通过顶部导航或直接打开记录页默认空间模式。
